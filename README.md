## Overview

In this lab, I Practiced Object-Oriented Programming (OOP) by building two small systems:

1. Simple Banking System
2. Library Management System

These programs demonstrate how real-world systems can be built using classed, objects and methods.


## What I Learned

During this week, I learned how to:

- Create and use multiple classes in one program
- Link classes together (Example: Customer -> Account)
- Use methods to preform actions like deposit, withdraw, borrow and return
- Store and manage data using lists and objects
- Build simple real-world systems using OOP
